# App Canal Martín García

PWA con viento, marea y alertas para el Canal Martín García (Río de la Plata).

- `docs/` — la app (se publica con GitHub Pages). Solo **lee** de Supabase con la clave pública.
- `supabase/functions/recolectar/` — robot que corre cada 5 minutos y guarda los datos.
- `herramientas/` — script para generar los íconos.

Fuentes: CARP (Norden, Colonia, Conchillas, Carmelo), Armada Nacional SOHMA (Colonia), Open-Meteo (ECMWF, GFS, ICON), SMN (alertas CAP).

> La app es una ayuda. No reemplaza la consulta de las fuentes oficiales para tomar decisiones de seguridad.
